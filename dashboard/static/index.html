ABOUT THE DATA

这些数据从哪里来

额度与重置时间

监控首次启动时，通过官方 Claude Code 的 /usage 查询全部账号一次。之后只读取 claude-auto 状态栏输出的 5h、7d 字段，不定时查询闲置账号，重启服务也会保留已有记录。新增加的账号位置会查询一次；“刷新全部”或账号右上角的刷新按钮可再次查询。

状态栏数据通常在模型响应后更新；没有活动时保留上次记录。网页每 5 秒读取本地记录。额度百分比并不是固定的 token 数。/usage 的百分比、重置时间使用官方界面的显示精度，时间约到分钟；状态栏时间可精确到秒。

为什么显示“待确认”

重置时间到了，但还没有收到新额度时，不会猜测已恢复为 100%。其他设备或 Claude 网页上的使用也可能使旧记录滞后，需要时可手动刷新。

一次查询只返回部分额度时，保留未返回窗口的最近记录并显示提示。会话收到的官方限额错误也会显示到预计恢复时间；当前有窗口运行不代表账号仍有额度。首页分别统计可用、达上限和待确认的账号。

重置卡

“查询重置卡”使用当前账号的官方登录查询卡片余额、适用范围和到期时间，同时更新返回的额度数据。页面标明查询时间，超过 5 分钟需重新查询；登录失效或接口异常表示“待确认”，不等于没有卡。停用账号会跳过。

“使用重置卡”先刷新卡片信息，并显示要使用的账号与邮箱。只有点击“确认消耗 1 次”才提交。提交结果不明确时不会重复使用；请先查询状态。手动备注仅供参考，不能作为使用依据。刷新网页不会自动使用或反复查询卡片。
